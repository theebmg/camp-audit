Privacy Policy

Sychar Operations — last updated September 14, 2026

Sychar Operations is an internal maintenance-management system built and operated for Camp Sychar (Mount Vernon, Ohio). It has a single operator and is not a public product or service — this page exists to describe how the system handles data, including data accessed through Google APIs, for that operator's own accountability and for Google's OAuth review process.

What this system is

Sychar Operations tracks the camp's buildings, grounds assets, work orders, maintenance findings, expenses, and photos, for the camp's own operations and board reporting. It is not available to the public and does not collect data from or about the general public, with the exception of the optional Maintenance Request form at /request, which any camp community member may use to report a maintenance issue (name, contact info, and a description of the issue, submitted voluntarily and used only to create and track that request).

Google account data

Sychar Operations integrates with Google Calendar (Calendar API, calendar.events scope only) so that scheduled maintenance work is visible on a calendar. Specifically:

  • The system creates a dedicated "Camp Work" calendar on the operator's own Google account — it never reads from or writes to the operator's primary calendar or any other calendar.
  • It creates, updates, and deletes events on that dedicated calendar only, mirroring scheduled maintenance work (job lines, deferred revisit dates, and similar) that already exists in the system's own database.
  • It does not read event content the operator or anyone else adds directly in Google Calendar. The relationship is one-way: this system writes to Google Calendar, it does not read from it.
  • No calendar data, or any other Google account data, is sold, shared with third parties, or used for advertising.
  • The Google account refresh token used to maintain this connection is stored in the system's own database, accessible only to the operator, and can be revoked at any time from the system's admin screen or from the operator's own Google Account settings.

Other data

Photos, documents, and records entered into the system (asset condition, work performed, expenses, and similar) are stored on the system's own database and object storage, used solely to operate and report on camp maintenance, and are not shared outside the system's operator and camp leadership.
